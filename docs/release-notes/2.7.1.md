# v2.7.1

Add `--outbound-mark` / `TG_OUTBOUND_MARK` for Linux policy routing and avoiding
transparent-proxy loops. Accepts decimal or `0x` hexadecimal 32-bit values. The
proxy sets `SO_MARK` before connecting, including connections
to HTTP/SOCKS upstream proxies. System resolver DNS queries remain unaffected.

The mark can also be configured through LuCI or UCI. The OpenWrt service grants
`CAP_NET_RAW` only when marking is configured (requires Linux 5.17+).
Invalid UCI marks are rejected before service startup.

Marking requires Linux capabilities; failures never fall back to unmarked
connections. Android and other non-Linux systems reject a configured mark.
Leaving it empty keeps existing behavior.
