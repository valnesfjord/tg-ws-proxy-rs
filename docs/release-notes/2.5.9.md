# v2.5.9

Windows 7 builds, and a Quick Settings tile for the Android app.

## Added

### Windows 7 and 8 builds (#156)

Two new archives: `tg-ws-proxy-x86_64-win7-windows-msvc.zip` for 64-bit and
`tg-ws-proxy-i686-win7-windows-msvc.zip` for 32-bit Windows.

The regular `x86_64-pc-windows-gnu` build cannot start on Windows 7. Since Rust 1.78 the standard
library calls Windows 8 and 10 APIs directly. Rust's `*-win7-windows-msvc` targets keep the old
fallbacks, but they are tier 3, so these builds use nightly Rust and build the standard library
from source. The C runtime is linked into the exe, so neither the Visual C++ redistributable nor the
Universal CRT has to be installed.

The release build checks the exe's import table and fails if it asks for anything Windows 7 does
not have, such as a dynamic CRT, `ProcessPrng`, `WaitOnAddress` or
`GetSystemTimePreciseAsFileTime`. Nothing in CI runs the binaries on Windows 7 itself; if one does
not start for you, please open an issue with your Windows version.

### Android: Quick Settings tile (#158)

Add **TG WS Proxy** from the tile editor in the notification shade. Tapping it starts or stops
the proxy with the arguments last saved in the app, and it shows the same running state as the
app's Start/Stop button. If a vendor build refuses to start the proxy from the tile, the tile opens
the app instead.

## What it costs

Two more release archives, built on Windows runners with a floating nightly, which is the part
most likely to break between two releases. `release-dryrun.yml` builds both on every pull request
that touches the release workflow or `Cargo.toml`/`Cargo.lock`, so a broken nightly shows up there
rather than on a tag.
